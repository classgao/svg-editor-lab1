# Lab1 Phase 1：SVG 命令行编辑器

当前状态：六种内置图形、全部命令入口、撤销重做及支持范围内的 SVG 读写已实现。2026-10-30 综合验收通过；最终提交、推送和 final 标签由本人手动完成。

## 运行与支持边界

在项目根目录运行 npm ci 安装固定依赖，npm run check 检查类型，
npm test 执行全部测试，npm run cli 启动编辑器。出现 svg> 后输入 help；
Ctrl+C 退出。examples/flowchart.svg 可拖入浏览器查看。

开发环境：Node.js 16.19.1、npm 8.19.3；.npmrc 使用项目相对缓存路径。

- 六类：rect、circle、ellipse、line、text、g；box 属后续阶段，不实现。
- 几何值须有限，尺寸与半径非负，画布宽高为正。init 单参数只指定宽度；
  canvas 修改时必须同时提供宽高。未初始化时允许 help。
- 成功 IO/画布修改清除旧历史并禁止 undo/redo，下一次成功编辑解除屏障；
  查询或失败命令不改变历史。成功的无效果排序仍是一个编辑单元。
- 显式 save 成功更新默认路径，read 成功使用读取路径，init 清除路径。
- 前景在同级数组末尾；跨父级 group 放到最近公共容器，按原树前序收编，
  插入最早涉及的直接分支之前；原空容器保留；根级 g 不允许 ungroup。
- g 样式按 SVG 继承，改变归属可能改变继承外观，不复制或换算样式。
- 外部 SVG 只接受六类及白名单属性、纯数值尺寸、匹配尺寸的 viewBox、
  文本实体/CDATA，普通 g 的 data-kind 降级。拒绝 transform、未知标签/属性、
  不匹配 viewBox、DOCTYPE 和外部命名空间，避免静默丢失含义。
- 实验背景的 transform 示例不能直接导入；如课程验收要求支持该类文件，
  需要另行扩展，不将当前结果宣称为完整 SVG 标准兼容。
- CLI 支持双引号包裹空格及空文本，未实现引号内反斜杠转义；
  颜色字符串保留，不实施完整 CSS 校验。

## 架构方案

### 模块划分

| 计划目录 | 职责 |
| --- | --- |
| src/cli | REPL、引号参数解析、命令分发与反馈 |
| src/application | 编辑器会话、命令执行、撤销重做历史 |
| src/application/commands | 各编辑命令类；一条编辑命令为一个撤销单元 |
| src/application/ports | 文档存取接口 |
| src/domain | 文档、全局 id 查找、父子关系和树结构约束 |
| src/domain/shapes | 图形抽象、五种叶子图形与 Group |
| src/infrastructure | SVG XML 解析、序列化和文件读写 |
| src/main.ts | 程序入口和依赖组装 |

上述目录均已实现；tests 保存可重复运行的回归与验收测试。

### 设计模式的选择

- Command（必需）：编辑命令封装执行与撤销，历史管理器维护 undo/redo 栈。失败命令不入栈，不清除 redo，也不改变文档。
- Composite：叶子与 Group 提供统一操作接口，容器移动和缩放递归委托给子节点，避免命令层按图形类型分支。
- Factory：集中处理类型名到具体图形类的创建映射；SVG 导入复用工厂。
- Command 当前代码落点：
  src/application/commands/EditCommand.ts 定义命令契约；
  src/application/CommandHistory.ts 管理执行、撤销和重做；
  EditorSession 负责调用并在成功的文档操作后设置历史屏障。
  已实现创建、移动、缩放、删除、属性设置、分组、解组、移动归属和排序命令。
- Memento（轻量实现）：captureGeometry 返回恢复几何状态的闭包。
  状态由图形内部封装，MoveCommand 无需读取私有字段。
按名字分派仅允许命令分发与图形工厂两处；按实验要求列为待重构项，未来可替换为注册机制。本阶段不实现 box 或插件系统。

### 依赖方向规则

- cli 可以依赖 application；不直接操作文件系统或修改图形字段。
- application 可以依赖 domain；通过 ports 使用文档存取能力，不依赖 infrastructure。
- domain 不依赖 application、cli 或 infrastructure，不执行终端和文件 IO。
- infrastructure 可以依赖 application/ports、domain 及 application/ShapeFactory；导入复用唯一工厂，避免第三处类型分派。此特例已纳入自动检查。
- main 负责组装，可以依赖各模块。

以上规则将领域行为与输入输出隔离，便于测试和替换交互方式。

### 变化点假设

1. 交互方式可能增加 GUI 或 agent：保留 application 层供不同入口调用。
2. 图形类型可能增加：使用多态及集中工厂；暂不实现插件加载器，避免超出本阶段范围。
3. 文件存储方式可能变化：通过 DocumentStore 接口隔离。
4. 撤销实现可能优化：由命令保存恢复所需的状态；先保证精确恢复，不提前做压缩或持久化历史。

### 第二步：实现基础 REPL

### 第三步：参数解析与错误处理

### 第九步：图形缩放与撤销

- 验证结果：两倍缩放、撤销和重做均正确。

### 第十四步：文字图形与文本修改

- 新增 Text 类及工厂入口，create text 支持引号内空格和空字符串。

### 第十五步：容器、创建归属和递归显示

- 新增 Group，通过 Composite 递归委托 move/scale；外层保留几何快照，
  任意后代失败时回滚整组，避免部分子节点已变更。
- 所有 create 类型支持尾缀 in；类型相关的参数判断集中在 ShapeFactory。
  文本内容本身为 "in" 时不会误当成归属子句。
- 文档改为有序根节点与 Group 有序子节点；当前通过递归遍历执行全局 id 查找，
  暂不维护第二套 id 索引，减少一致性风险。查找为 O(n)，本实验规模下接受。
  此项替代先前“立即拆出全局索引”的方案，未来有性能需求时再加入索引。
- 文档管理校验全文档 id 唯一；删除整棵子树，撤销恢复原父级、位置和对象。
- tree 递归输出层级；tree id 展示子树；show 显示实际父级。
- set g 的公共样式保存在容器上，供 SVG 继承使用，不覆盖子节点显式样式。
- 新增 tests/groups.cjs；全部六组测试通过，覆盖六类图形的 in、嵌套变换、
  失败回滚、子树删除恢复、唯一 id、错误父级、循环防护及历史不变性。
- group/ungroup/addto 和层级重排尚未实现，留给下一独立阶段。
### 第十六步：分组、解组与移动归属

- 新增 GroupCommand、UngroupCommand、AddToCommand，由文档封装层级修改。
- 分组按原树前序排列选中图形；同父级插入最早选中位置。
  跨父级放入最近公共容器，在包含选中图形的最早直接分支之前插入；
  保留未被选中的原容器，即使它变空。此为文档未明确部分的实现约定。
- 拒绝重复目标、缺失 id、容器与自身后代同时分组、移入自己或后代。
- ungroup 拒绝根级容器；嵌套容器子节点按原顺序提升到原位置。
- addto 追加为最后子节点；同父级调用时移动到末尾。
- 层级操作先校验，并用层级快照保证失败恢复；一次操作为一个历史单元。
- 关键迭代：重做若重新创建分组对象，会使后续 MoveCommand 引用旧对象。
  改为保存操作前后层级快照，重做恢复同一对象；新增连续分组/移动撤销重做测试。
- 层级快照只保存父子关系和顺序，不覆盖几何与样式；不进行坐标换算，
  普通容器样式仍使用 SVG 继承语义，归属变化可能改变继承外观。
- tests/hierarchy.cjs 覆盖同级与跨级分组、对象身份、删除与解组组合、
  空容器、顺序恢复、循环拒绝和失败保留历史；全部七组测试通过。
- 本阶段不实现 box；front/back 留到下一次独立提交。
### 第十七步：同级图层顺序

- 新增 ReorderCommand，front 将图形移到同级数组末尾，back 移到开头。
  SVG 后绘制的元素覆盖先绘制的元素，因此数组末尾对应视觉最上层。
- 调整仅影响同级顺序，保持原父级、几何、样式、对象身份及容器子树不变。
- 撤销通过层级快照恢复原顺序；失败操作不改变图形或历史。
- 已在目标位置的 front/back 仍视为成功编辑，按一条命令一个历史单元处理。
- tests/order.cjs 覆盖根级和嵌套排序、容器及唯一子节点、连续撤销重做、
  无效参数、不存在 id、删除恢复、新编辑清空 redo 及 IO 屏障。
- 类型检查、全部八组回归测试通过；实际 SVG 重叠渲染待文件保存阶段验证。
### 第十八步：SVG 保存

- 新增 DocumentStore 存储接口、SvgSerializer 和 FileDocumentStore。
  main 注入实现，application 不依赖文件系统，domain 不依赖 XML 或 IO。
- 图形通过多态提供几何/样式属性副本和文本内容，序列化器不按类型分支。
- save 输出 SVG 命名空间、画布尺寸、viewBox、有序嵌套节点。
  文本为子文本，转义 XML 特殊字符并拒绝非法 XML 字符；缺省样式不补写。
- 文件先写入同目录临时文件再重命名替换，失败清理临时文件。
  保存成功才更新当前路径并设置历史屏障；失败保留文档、路径和历史。
- 路径约定：显式 save 成功后记住该路径，无参数 save 复用；init 清除路径。
- 元素计数包含 g 和所有后代，不含 svg 根；示例流程图为 8 个元素（3 个 g、2 个 rect、2 个 text、1 个 line）。此前将其计为 9 是分析错误，现按实际结构纠正。
- tests/save.cjs 验证六类节点、特殊字符、路径空格、重复覆盖、
  缺失目录失败、原文件保护、排序及历史屏障；全部九组测试通过。
- 已通过真实 CLI 生成 examples/flowchart.svg，可用浏览器直接打开。
  本阶段未进行浏览器视觉验收，最终综合阶段补充；read 尚未实现。
### 第十九步：SVG 读取与往返

- 安装并固定 @xmldom/xmldom 0.9.12，使用本地类型声明核对解析 API。
- 新增 SvgReader；FileDocumentStore 负责文件读取，ShapeFactory 负责类型还原。
- 先扫描全部显式 id，检查重复，再为缺失或空 id 按类型加序号分配并告警。
  自动编号跳过文件后面已有的同名 id；保留大小写敏感约定。
- 读取建立独立临时文档，全部成功后才更新当前文档、默认路径和历史屏障；
  失败不输出未完成导入的补号警告，不破坏已有文档或 redo。
- 支持六种内置类型、嵌套 g、公共样式、文本实体及 CDATA；
  缺失几何属性按零处理；data-kind 标记降级为普通内置图形语义。
- 范围限制：仅数值尺寸和匹配尺寸的 0 0 width height viewBox；
  未知标签/属性、transform、DOCTYPE、外部命名空间和嵌套叶子均拒绝。
  本实验背景中的 transform 示例因此不能直接导入，属于明确的支持边界，
  不将其默认为已支持完整 SVG 标准。
- tests/read.cjs 验证六类往返、自动补号避让、重复 id、非法 XML、
  文本实体/CDATA、失败保留历史、读取路径默认保存；全部十组测试通过。

## 一致性自查

1. 模块划分：cli、application、commands、ports、domain、shapes、
   infrastructure 和 main 均已实现。工厂位于 application，id 使用递归查找，
   与初版差异已记录在修订及过程记录中。
2. 依赖方向：自动扫描相对导入与外部依赖，domain 无 IO/上层依赖，

5. 历史快照与递归查找存在 O(n) 成本，适用于实验规模；
